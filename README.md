# Cashier Management System — Frontend-only Demo

This is the cleaned **existing CMS frontend prototype**, not the earlier database-backed system.

## Login (development demo only)
- cashier / cashier12345

## Run locally
```bash
npm install
npm run dev
```

## Notes
- No Supabase connection, migrations, SQL, API routes, or backend services.
- UI uses in-memory sample data, which resets on browser refresh.
- Demo credentials are hardcoded in the client and **must not** be used for production access.
- Future modules are placeholders until rebuilt.
